English Verb Trainer

Escribí un verbo y practicá presente simple, presente continuo y pasado simple. El ejercicio mezcla afirmaciones, preguntas y negaciones. El sujeto siempre queda visible; vos completás únicamente el verbo o la estructura verbal.

Podés escribir el verbo como write o to write: el entrenador elimina “to” automáticamente. Para verbos regulares dejá “Pasado” vacío: work → worked. Para irregulares escribilo: write → wrote, go → went.
